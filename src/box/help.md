# 1. 快速上手

## 1.1 界面一览

![BVM 的界面：① 顶栏 ② 素材库 ③ 属性面板 ④ 3D 视图 ⑤ 状态栏 ⑥ 选择条](ui-overview.webp)

- **顶栏**：分三块。左边是文件菜单（新建、打开 / 保存、历史地图，以及「地图码」「导出」「测试场景」三个二级菜单）、地图名和撤销重做；中间是工具；右边是对齐与格栅、当前小节、显示开关，以及主题、设置、帮助。
- **素材库**：路面、钢轨、木制件、机关、道具、装饰都在这里。最前面的「常用」标签里是你收藏的（点卡片右上角的星标）和最近放过的素材。标题栏上的三个小按钮可以把它停靠在左边、右边或底部，拖它的边缘能改大小。
- **属性面板**：选中一个东西后出现，可以直接改数值。数字框可以左右拖动，按住 Shift 微调。
- **3D 视图**：在这里摆放和编辑。
- **状态栏**：左边随时提示当前能按的键，拿不准的时候先看这里；右边是选中东西的尺寸。
- **选择条**：选中东西后出现在视图下方，放着对选中的东西能做的事：复制、转 90°、聚焦、镜像、合并、绑定、孤立、删除。

> 悬停在按钮上时按 [[F1]]，会直接跳到这个按钮相关的教程。

## 1.2 视角与漫游

### 环视、平移、缩放

按住鼠标中键拖动是环视，[[Shift]] + 中键是平移，滚轮缩放。点右上角视图立方体的一个面，会切到那个方向的正视图；再环视就回到透视。

![环视、平移、缩放和正视图](demo:view-orbit)

### 聚焦

按 [[F]] 把视角对准选中的东西；什么都没选时看全部。

在设置里打开「自动追踪」后，点选东西时视角会自动移到它上面：不会拉近，离得太近时会拉远一点。默认是关的。

![点选时视角跟过去，按 F 聚焦](demo:view-focus)

### 漫游

按住右键进入漫游，像玩游戏一样用键盘移动视角，松开右键就退出。按键都显示在画面上，照着按就行。

![漫游时画面上的按键提示](view-fly.webp)

## 1.3 基本操作

### 放置

从素材库把卡片拖进场景，松开就放下。拖动中按 [[R]] 转向，右键取消。只点一下卡片，会放到视图中心。

### 工具

顶栏中间是工具，总有一个在用（蓝色），分成三组：

- **选择**（[[Q]]）：默认的工具，只负责点选和框选。别的工具用完，按 [[Esc]] 或点「选择」回到这里。
- **移动、旋转、拉伸、坡面**（[[1]]～[[4]]）：改选中的东西，在它上面显示各自的手柄：移动是箭头，旋转是圆环，拉伸、坡面是边上的抓点。
- **切分、花纹、护栏**（[[5]]～[[7]]）：直接在路面上点。

怎么切换：

- 点按钮或按数字键，按钮变成**蓝色**；再点一次同一个按钮也是回到选择。
- 按住 [[G]] / [[R]] / [[Ctrl]] / [[Alt]] / [[K]] / [[P]] 临时切到移动 / 旋转 / 拉伸 / 坡面 / 切分 / 花纹，按钮变成**橙色**，松开就回到原来的工具。
- 鼠标指针右下角的小图标就是当前工具，颜色和按钮一样。
- 手柄可以在「显示」菜单里关掉。所有快捷键都可以在 设置 → 快捷键 里改。
- 手机上点按钮切换，手指拖手柄。

### 移动

按 [[1]] 切到移动工具：直接拖东西就是在水平面里移动；按住红、绿、蓝箭头（X / Y / Z）拖，就只沿那个方向走。松手确定，吸附、对齐照常生效。

![移动工具里拖箭头沿 X、Z 移动](demo:op-gizmo)

### 自由移动（G）

选中后轻按一下 [[G]]，东西跟着鼠标走，左键确定，右键或 [[Esc]] 取消。

移动中按 [[X]] / [[Y]] / [[Z]] 只沿这个轴走，[[Shift]] + 轴是排除这个轴（比如只在水平面里移动）。直接输入数字可以精确移动，[[Enter]] 确定。

默认是**游戏坐标系**：Y 朝上，位置数字和 Ballance 里一致。想用 Z 朝上，可以在设置里换成**数学坐标系**，轴的名字、颜色、按键和属性面板都会跟着换，地图本身不受影响。

![G 移动、X 限轴、输入距离](demo:op-grab)

### 旋转

按 [[2]] 切到旋转工具：按住红、绿、蓝圆环拖动，就绕 X / Y / Z 轴转；直接拖东西是绕竖直轴转。开着对齐时每 15° 吸一下。

![旋转工具里拖蓝色圆环绕竖直轴转](demo:op-rotate)

也可以选中后轻按一下 [[R]]：东西跟着鼠标转，按 [[X]] / [[Z]] 换成绕水平轴转，按住 [[Ctrl]] 临时切换 15° 吸附，左键确定。

只想转个直角时，点选择条上的「转 90°」。

### 选择条：复制、删除

选中东西后，视图下方出现选择条，对选中的东西能做的事都在上面：**复制、转 90°、聚焦**，能镜像、合并、绑定、解绑时也会出现对应的按钮，然后是**孤立**和**删除**。

[[Shift]] + [[D]] 复制，复制出来的直接进入移动，左键放下。[[X]] 或 [[Delete]] 删除。

![复制并放下，再删除](demo:op-dup)

### 复制到别的地图

[[Ctrl]] + [[C]] 把选中的东西放进剪贴板，[[Ctrl]] + [[V]] 粘贴：粘贴出来的跟着鼠标走，左键放下，右键取消。剪贴板里是一小段文字，所以换一张地图（文件 → 历史地图、新建）以后照样能粘贴，也可以发给别人。[[Ctrl]] + [[X]] 是剪切。

## 1.4 构建路面

### 拉伸、拉坡、改厚度

- **拉伸工具**（[[3]]，或按住 [[Ctrl]]）：拖边上的蓝色方块改长宽，拖朝向你那一面底边上的橙色方块改厚度；直接拖路面的某条边也行。钢轨拖两头改长度，木板这类能拉伸的木制件也是这样拉。木桥、波浪板、倾斜木板、木制斜坡、U 型木板（长）这类花纹重复的木制件，沿长度方向拉的时候不会被拉变形：拉长是把花纹一段一段接上去，拉短是截断。拉哪一头就在哪一头接上或截断，另一头原样不动；被拉的那一头会吸到半个周期的整数倍（波浪板就是波峰和波谷）。
- **坡面工具**（[[4]]，或按住 [[Alt]]）：拖边上的黄色圆圈，把那一边往上或往下拉成坡；直轨拖两头改高差。

按着 [[Ctrl]] 或在拉伸工具里，拖路面侧面的下半截也是改厚度，上半截和顶面还是改尺寸。鼠标移动时，这次拖动要操作的那个抓点会变白放大。厚度超过 5 时，侧面下半截会换成没有边框的材质，和原版一样。

![拉伸工具拉长、加厚，坡面工具拉坡](demo:road-stretch)

### 自动花纹

同样式、同高度的路面贴在一起就连成一片，边框花纹自动接上，不用手动处理 UV。不同样式的路怎么接，见 [2.1 路面](#2.1)。

![拼成丁字路口时花纹自动接上](demo:road-auto)

### 开口与封口（花纹工具）

按 [[6]] 切到花纹工具（或按住 [[P]]），选中的路面每条边的中点有一个小开关，点一下依次切换：

- **自动**（灰点）：贴着同样的路面就连成一片，否则画边框
- **开口**（绿圈）：不画边框，比如接自己做的模型
- **封口**（橙色菱形）：贴着别的路面也画边框

接机关（软木桥、跷跷板、终点气球等）和特殊路块 16 的路端会自动开口，一般不用手动设。

![切换开口和封口](demo:road-open)

## 1.5 切分与合并

### 切分：在路中间做坡

点顶栏的「切分」或按 [[5]]（或按住 [[K]]），在鼠标处把路切成两段，[[Tab]] 换方向，右键或 [[Esc]] 回到选择。切开以后给其中一段拉坡，就能在一条长路的中间做坡。

![切开后给后半段拉坡](demo:split-slope)

### 合并

选中几块路面，点选择条上的「合并」或按 [[Ctrl]] + [[J]] 合成一块。只有同样式、同高度，并且合起来正好是一个矩形时才能合并；样式或高度不一样时，选择条上不会出现合并按钮。

![两块拼成矩形的合成一块；L 形合并不了](demo:merge)

## 1.6 大规模操作

在空白处拖动框选，按住 [[Shift]] 加选，[[Ctrl]] + [[A]] 全选。

点选择条上的「绑定」或按 [[Ctrl]] + [[G]]，把选中的东西绑成一组，之后点其中任何一个都会选中整组，一起移动、旋转、复制；「解绑」或 [[Ctrl]] + [[Shift]] + [[G]] 解组。

![框选、成组、一起移动](demo:group)

### 一起改属性

选中多个东西时，属性面板变成「已选 N 个」：可以一起改高度；里面有路面就能一起改样式和厚度，有钢轨能一起换单轨 / 双轨，有机关能一起改小节。数值不一样的显示「多个值」，填一个数就全部改成它。

### 镜像

选择条上的「镜像 X」「镜像 Z」（[[Ctrl]] + [[M]]、[[Ctrl]] + [[Shift]] + [[M]]）把选中的东西沿那个方向翻过去，镜面在选中整体的正中间。做对称的关卡时，摆好一半、复制、镜像就行。

- 路面（包括坡、开口和封口）、平凹转换、钢轨（直轨、弯轨、螺旋、侧轨、曲线钢轨）、曲线路面、弧形路面、护栏、死亡区都能镜像。
- 机关、木制件这些形状固定的模型、盘点，还有倾斜的东西不支持镜像：一起选中时它们留在原地，提示里会说跳过了几个。

### 孤立模式

选中东西后点选择条上的「孤立」（[[I]]）：只留下选中的这些，其余的全部藏起来，点不到也不会吸附过去，适合在很挤的地方细调。视图四周会有一圈橙色，选择条上一直有「退出孤立」，点它或再按一次 [[I]] 就把其余的放回来。

孤立时路面的花纹按只有这几块来算，所以和藏起来的路相接的地方会临时多出边框，退出后恢复。保存、导出、关卡检查看的始终是整张图。

## 1.7 精细控制

### 对齐

对齐（[[S]]，默认开）：移动、拉伸时，靠近别的东西的边、中线、顶面会贴过去，并显示绿色参考线；旋转时每 15° 吸一下。

![靠近时出现参考线并贴齐](demo:align)

### V 吸附

按住 [[V]]，抓住一个顶点或边中点，拖到别的东西上，会正好贴到对方的顶点或边中点。转过角度的东西也能这样精确拼上。选中曲线时，按住 [[V]] 拖控制点也会吸附：端点吸到路面或钢轨上会自动转向衔接，吸到自己的另一头就首尾相连。

![按住 V 把一个角贴到另一个角](demo:vsnap)

### 格栅

格栅（[[Shift]] + [[Tab]]，默认关）：位置和尺寸按步长取整，步长在设置里改（默认 1）。

方向键也能微调位置，每次 1，按住 [[Shift]] 是 0.1；[[PageUp]] / [[PageDown]] 调高度。

![开着格栅时长度一格一格跳](demo:grid)

## 1.8 在手机上使用

BVM 需要横屏使用。竖着拿时会提示你把手机横过来；安卓上可以点「全屏并横屏」，也可以从浏览器菜单「添加到主屏幕」，之后打开就是全屏横屏。iPhone 上请先关掉控制中心里的「竖排方向锁定」。

### 手势

- 单指在空白处拖动：环视
- 双指拖动：平移；双指捏合、张开：缩放
- 轻点：选中，轻点空白处取消选择
- 点顶栏的工具按钮切换工具，拖手柄：移动工具的箭头、旋转工具的圆环、拉伸 / 坡面工具的抓点；用完点「选择」（箭头）回去
- 长按不动，等手机轻震一下再拖：框选一次，框到的东西加进选择
- 工具旁边的多选按钮（虚线方框）打开后，单指拖动都是框选，轻点是加选 / 减选，再点一下关掉
- 按钮只剩图标时，点了之后顶上会提示切到了哪个工具
- 拉伸、拉坡等单指拖动时视角不会跟着转，底部提示栏显示当前能用的手势
- 选中后，视图下方的选择条上有复制、转 90°、聚焦、合并、绑定、删除和取消选择，都是大按钮
- 点复制后，单指拖动摆放副本（按在哪里都行，可以拖好几次），轻点放下，中途可以双指调视角
- 双指操作视图时其他操作都不生效；单指编辑中途放下第二根手指，这次编辑会撤回

### 平板

平板上用的是电脑的布局，手势和手机一样：单指环视、双指平移缩放、轻点选中、长按再拖框选，选择条是大按钮。接了鼠标或触控板的平板按电脑算。

### 界面

- 帮助、设置、主题、全屏收在顶栏最右边的「⋯」里；屏幕窄的手机上，对齐和格栅也在里面。手柄的开关在「显示」（眼睛）菜单里。
- 素材库竖着滑动翻页。按住卡片一会儿（手机轻震）或者横着拖出来，才开始摆放，轻点不会放东西。
- 从素材库拖出卡片时，素材库会自动收起，整个视图都能放；点右边的窄条展开。
- 属性面板点标题可以收起成一行，不挡视图。

> 顶栏的工具按钮都能点：切到移动、旋转、拉伸、坡面工具，用手指拖手柄就能编辑，不需要键盘。

# 2. 设计关卡

## 2.1 路面

### 路面是一块一块的

BVM 里每块路面都是一个独立的长方体，块和块之间没有“连接”关系。贴在一起、样式和高度相同的就算一片路面，花纹、开口、转换每次都按位置重新算。所以随便摆、随便改，结果都是对的；重叠的部分只画一次。

![拖动一块路，花纹实时跟着变](demo:box-model)

### 平路、凹路与转换

路面有平路、凹路、细边框凹路三种。不同样式直接贴在一起不会自动处理，两边各画边框。

- 平路接凹路：放一块 **平凹转换**（长 5，一头平一头凹），按 [[R]] 调方向
- 凹路接细边框平台：用 **窄转换**（长 2.5）
- 转换件只接在路的两端，侧面不接

![平路和凹路之间放一块平凹转换](demo:transition)

### 平台自动衔接

路接到大平台（宽路面）的侧面时，样式不同也不用手动放转换件，平台的边框里会自动嵌一块衔接。

![凹路平台的侧面接一条平路](demo:platform)

### 坡

坡只在上下两头和别的路相接，侧面不接。

参考：[制图手册 · 路面与钢轨](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/floor-and-rail.html)

## 2.2 钢轨

### 单轨、双轨与单双转换

直轨默认是双轨，在属性面板的“轨型”里切换单轨、双轨、单双转换。[[Ctrl]] + 拖改长度，[[Alt]] + 拖做坡。

![切换轨型，拉长](demo:rail-kinds)

### 弯轨与螺旋

弯轨在属性里调半径和角度；螺旋调半径、圈数和每圈升高。

![改弯轨的角度和螺旋的圈数](demo:rail-curve)

**曲线钢轨**可以做任意走向的钢轨。从素材库放下后选中它，线上的箭头指向曲线的走向：拖控制点水平移动，拖橙色圆圈改高度，拖方块调方向；按住 [[V]] 拖控制点可以吸到别的钢轨或路面上，端点吸到钢轨的端头会顺着它自动转向。属性面板里能加点、删点、切换双轨和单轨。

每个控制点的两根手柄默认是**对称控制柄**（蓝色），拖一边另一边镜像跟着；在属性面板里换成**分离控制柄**（粉色）后，两边的长度各调各的，方向仍然在一条线上。

曲线可以**首尾相连**：点属性面板的按钮，或者按住 [[V]] 把端点拖到另一头。环形的曲线可以用切分工具点任意位置断开，也可以在属性面板里从选中的控制点断开，断开后拖端点把两头分开。

截面默认是**竖直**的，两头能和现有的路面、钢轨接平。要做竖直爬升、翻圈或侧倾，把截面切到**平行传递**，再给每个控制点设侧倾角。

**曲线路面**在路面标签里，操作和曲线钢轨一样，可以选平路、凹路、细边框凹路和厚度。把端头的控制点按住 [[V]] 吸到路面边的中点上，方向会自动转正，两边自动开口接上；护栏也能沿曲线路面的边放。两头也可以在属性面板里手动设成开口或封口。

**弧形路面**也在路面标签里，是一段圆弧：属性面板里调半径、角度和左转右转，转满 360° 就是圆环。样式、厚度、自动接路面和曲线路面一样；端头对着路面边的方向时会自动开口接上。

### 侧轨

侧轨是两根成角度的钢轨，拖到路面上会贴住最近的路边。属性里可以把上轨的起点、终点“弯下”，固定在路边。螺旋侧轨是单轨螺旋，每圈升高固定。

![侧轨移到路边贴住，上轨两头弯下去](demo:rail-side)

### 端点闭合与立起来的钢轨

钢轨两头可以选平直或球形闭合。钢轨能绕水平轴 转：转 90° 立起来，就是一根 Tip。

![球形闭合；立起来当 Tip](demo:rail-tip)

参考：[制图手册 · 路面与钢轨](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/floor-and-rail.html)

## 2.3 机关与归组

### 归组

游戏靠“组”来识别物体：路面要进物理化组、声音组、影子组，机关要进对应的小节。导出 NMO 时 BVM 会按规范自动归好，一般不用管。

参考：[制图手册 · 归组](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/grouping.html)

### 小节

起点是第 1 小节，每放一个小节盘点就多一个小节。新放的机关归到顶栏当前选中的小节，属性面板里能改。在「显示」菜单里打开小节标签，机关头上会显示它属于第几小节。

![顶栏切换当前小节；打开小节标签后，机关头上显示它属于第几小节](sector.webp)

### 以推板为例：对准方块

每个机关都有对准方块（拖动、选中时显示成橙色虚线框），它会吸附到路面上、嵌在路面里，高度自动对上。

推板这种两头接路的机关有两个对准方块。先摆好两段路，把推板拖过去，让两个方块分别嵌进两段路的端头，路端会自动开口。机关不会改动路面，路要自己摆。

![把推板移到两段路之间：两个对准方块嵌进路端，路端自动开口](demo:module-anchor)

### 挡块与专属路块

推板这类机关会自动配上原版的木头挡块。在花纹工具（[[6]]）里选中机关，每块挡块上有个小圆圈，点一下切换生成或不生成（关掉的显示成红色虚影）。

风扇、变球器、栅栏会自动换上专属路块，在属性面板里可以关掉。

![逐块关掉挡块；风扇移到路上，脚下换成风扇底座](demo:module-stopper)

参考：[制图手册 · 机关与道具](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/module.html)

## 2.4 装饰

### 护栏

点顶栏的「护栏」或按 [[7]]（[[H]] 也行）切到护栏工具：点路边放一整条直边（两头各往里缩 1.5，不顶在路的拐角上，设置里可改），沿路边拖放一段（可以绕过拐角），拖两头的把手改长度，[[Esc]] 回到选择。高度、立柱深度等在设置里改，整张图一起生效。

护栏会跟着它贴着的路面走：路面移动、旋转、抬高、拉成坡时护栏跟着变；拉长或缩短路面时，靠着拐角的那一头跟着拐角走，所以整条直边的护栏还是整条直边。护栏也可以单独选中移动，挪开以后就不再跟着路面了。

![点直边、沿路边拖、拖把手](demo:guard)

### 柱子与灯塔

“柱子（支撑）”会对准它头顶的那一格路面，柱头顶在路面底下。“灯塔”是独立的灯柱，放在路边或空地都行。

![柱子移到悬空路面的正下方，柱头顶在路面底下](demo:column)

### 云层

装饰里有云层和漩涡云层，一张图只导出一个。「显示」菜单可以在编辑器里隐藏云层，不影响导出。

参考：[制图手册 · 游戏内装饰](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/decoration.html)

## 2.5 死亡区

死亡区在素材库的机关标签里，球碰到就死。它和路面一样能拉伸、移动；导出时自动隐藏，并归进 DepthTestCubes 组。「显示」菜单可以在编辑器里隐藏它。

![Ctrl 拖两边，把死亡区拉成一大片](demo:zone)

参考：[制图手册 · 死亡区](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/depth-test-cube.html)

# 3. 文件与分享

## 3.1 导出 NMO

文件 → 导出 → 导出 NMO，在浏览器里直接生成，文件名就是顶栏的地图名。把它放进游戏的地图目录就能玩。

文件菜单里带箭头的是二级菜单：鼠标移上去就会在右边展开；触屏上点一下在原地展开。

### 关卡检查

导出前会先检查一遍关卡，有问题时列出来，点其中一条可以直接跳到相关的东西上。也可以随时从 文件 → 检查关卡 打开。

- **红色：游戏会拒绝加载。** 没有起点、没有终点飞船。
- **橙色：能玩，但有问题。** 只有一个小节（开头的火焰会显示成三角形，而且进关后按 Esc 打不开菜单）、小节超过 8 个、机关的小节号超出范围、有多个起点或云层、没有云层、没有死亡区。

橙色的提醒不妨碍导出。

参考：[制图手册 · NMO 文件](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/nmo-file.html)

## 3.2 地图码

文件 → 地图码 → 复制地图码，得到一串文字，发给别人；对方用 文件 → 地图码 → 导入地图码 粘贴就能打开。

![导入地图码：把别人发来的一串文字粘贴进去](share-code.webp)

## 3.3 历史地图

地图会自动存进历史，最多留 100 张。[[Ctrl]] + [[O]] 打开列表，可以打开、重命名、删除。

> 历史只存在这台电脑的这个浏览器里，清除网站数据就没了。重要的地图记得存成文件，或者复制地图码另存一份。

## 3.4 地图文件

文件 → 保存为文件，把当前地图存成一个 `.bvm` 文件放在电脑上，文件名就是地图名。以后用 文件 → 打开地图文件 打开，或者直接把文件拖进窗口；打开的地图会成为一张新的历史地图，原来正在编辑的那张还在历史里。

文件打不开时会弹出提示，说明是哪个文件、什么原因（不是 BVM 的文件、内容不完整、是更新版本存的）。

# 4. 常见问题

### 为什么这里出了边框，没有接上？

常见原因：两边样式不同（要放转换件）、高度差了一点点、某一边被手动设成了封口，或者路面绕水平轴 倾斜了（倾斜的路面自己成一块，不和别的路拼花纹）。

### 为什么倾斜的钢轨拖不动？

钢轨倾斜以后，长度和高差要在属性面板里改。
### 导出 OBJ / glTF

想在 Blender 等建模软件里看看、或者接着加工，用 文件 → 导出 里的另外两项：

- **glTF（.glb）**：一个文件，贴图转成 PNG 嵌在里面，大多数 3D 软件和网页查看器都能直接打开。
- **OBJ（.zip）**：压缩包里是 `.obj`、`.mtl` 和用到的贴图（游戏里的原文件），解压后打开 `.obj`。

导出的内容和 NMO 完全一样：机关、火焰、重生点、气球是游戏用的**占位符**（和导出 NMO 时一样的方块、标记），不是编辑器里看到的样子；物体名字也和 NMO 一致。坐标是 Y 朝上，单位和游戏相同。glTF 里每个物体还记着它属于哪些组（节点的 extras 里），死亡区标成了隐藏；OBJ 不支持隐藏，死亡区照样导出，名字以 DepthTestCubes 开头。

这两种格式不能放进游戏，也不能再导回 BVM；导出前不做关卡检查。


### 为什么机关没有挡块或专属路块？

机关绕水平轴 倾斜了，或者在属性面板 / 挡块圆圈上关掉了。

### 进游戏后漩涡云层是黑的，或者球有两层影子？

这是旧版本导出的地图，重新导出一次就好。
