# 帮助手册：章节与录制脚本

> 已实现：正文在 `src/box/help.md`，弹窗在 `src/box/help.ts`，一页一个小节。动图改成了实时演示：帮助弹窗里嵌一个只有 3D 视图的编辑器（`?demo=名字`），按 `src/box/demos.ts` 的分镜自动操作（播放器 `src/box/demo.ts`，检查脚本 `scripts/help/check-demos.mjs`）；界面、菜单、漫游用截图（`scripts/help/stills.mjs`，`scripts/help/screenshots.mjs` 截）。素材库拖放这类简单操作只写文字。下面是最初的方案。

## 形式

- 入口：顶栏「关于」旁边加「帮助」，快捷键 F1 或 ?。第一次打开编辑器时弹一个能关掉的小提示：“左键选择，G 移动，按 F1 打开帮助”。
- 左侧是章节目录，右侧是一篇像 markdown 文档的页面：文字和动图交替排下去。一个小节里放几项相近的内容，每项是一两段文字加一张动图；有的项只配截图，或者只有文字。
- 动图用 animated WebP：`<img>` 直接循环播放，不需要播放器控件，体积比 GIF 小得多；加 `loading="lazy"`，滚到时才加载。走现有的离线缓存。
- 工具按钮、素材库卡片的悬停提示加一行「详细 →」，跳到对应小节的锚点。
- 动图用脚本录：每张图的场景和操作写成一段脚本（放在 `scripts/help/`），录成帧后用 ffmpeg 转 WebP。界面变了重跑一遍就能更新。
- 制图手册的相关章节直接给链接（`https://ghomist.github.io/ballance-mapping-manual/` 下），这里只讲 BVM 里怎么做，不展开底层原理。

下面每项的格式：

- **文字**：正文要讲的内容（成稿时再润色）。
- **动图**：开场（录制前用 `__proto` 直接摆好的场景）→ 动作（录制时执行的操作），约几秒。没写动图的项不配图。

## 1. 快速上手

### 1.1 界面一览

- **文字**：顶栏（文件、撤销重做、工具、编辑按钮、格栅 / 对齐、小节、显示）、素材库（可以停靠在左边、右边或底部，标题栏上切换）、属性面板（选中东西后出现）、3D 视图、状态栏（随时提示当前能按的键，拿不准的时候先看这里）。
- **截图**：默认场景，选中一块路，五个区域加编号标注。

### 1.2 视角与漫游

**环视、平移、缩放**
- **文字**：中键拖动环视，Shift + 中键平移，滚轮缩放。点右上角视图立方体的面切到正视图，再环视就回到透视。
- **动图**：默认场景 → 中键环视半圈 → Shift + 中键平移一段 → 滚轮拉近 → 点立方体“顶” → 中键拖一下回到透视。约 8 秒。

**聚焦**
- **文字**：按 F 看选中的东西，没选中时看全部。打开设置里的自动追踪后，点选东西时视角会自动移过去（默认关）：不会拉近，离得太近时拉远一点。
- **动图**：默认场景，视角在起点 → 点终点气球，视角移过去 → 按 F 拉近 → 点空白处、按 F 看全部。约 6 秒。

**漫游**
- **文字**：按住右键进入漫游，像玩游戏一样移动视角，松开右键退出。按键画面上都有提示。
- **动图**：一条长路加几个机关 → 按住右键，往前走一段，转两下视角 → 松开。约 5 秒。

### 1.3 基本操作

**放置**
- **文字**：从素材库把卡片拖进场景放下；拖动中按 R 转向，右键取消。点一下卡片会放到视图中心。
- **动图**：空地上一块路 → 拖“平路”到旧路旁边放下，花纹自动接上 → 拖“凹路”时按一次 R 再放下 → 再拖一张卡片，右键取消。约 7 秒。

**移动**
- **文字**：选中后按 G 移动，鼠标跟着走，左键确定，右键取消。移动中按 X / Y / Z 只沿这个轴走，Shift + 轴是排除这个轴；直接输入数字可以精确移动。
- **动图**：选中一块路 → G 随意移动 → 按 X 只能横移 → 输入 10 → Enter → 再按 G，然后右键取消。约 7 秒。

**旋转**
- **文字**：选中后按 R 旋转，默认绕竖直轴转；按 X / Y 换成绕水平轴。开着对齐时每 15° 吸一下，按住 Ctrl 自由旋转。
- **动图**：选中一个机关 → R 转 90° → 左键确定 → 再按 R 转 45° → 左键确定。约 5 秒。

**复制与删除**
- **文字**：Shift + D 复制，复制出来的直接进入移动，左键放下。X 删除。
- **动图**：选中一块路 → Shift + D，拖到旁边放下 → 再选中它按 X。约 5 秒。

### 1.4 构建路面

**拉伸、拉坡、改厚度**
- **文字**：选中路面后，Ctrl + 拖改长宽，Alt + 拖一头做坡，Ctrl + 拖侧面下半截改厚度。厚度超过 5 时，侧面下半截换成没有边框的材质，和原版一样。
- **动图**：选中一块 5×20 的平路 → Ctrl 拖端面拉长 → Alt 拖端头抬高成坡 → Ctrl 拖侧面下半截到厚度 8，镜头转到侧面。约 8 秒。

**自动花纹**
- **文字**：同样式、同高度的路面贴在一起就连成一片，边框花纹自动接上，不用手动处理 UV。不同样式怎么接，见 2.1。
- **动图**：一条直路 → G 拖一块路贴到侧面，接缝处的边框消失，变成丁字路口 → 再拖开，边框回来。约 6 秒。

**开口与封口**
- **文字**：选中路面后，每条边中点有个小开关，点一下依次切换自动 → 开口 → 封口。开口：不画边框（比如接机关、接自己做的模型）；封口：贴着别的路也画边框。
- **动图**：两块相接的路，选中一块 → 点相接那条边的开关切到开口、再切到封口，出现边框 → 再点回自动。约 6 秒。

### 1.5 切分与合并

**切分：在任意位置做坡**
- **文字**：按 3 进入切分，在鼠标处把路切成两段，Tab 换方向。切开后给其中一段拉坡，就能在一条路的中间做坡。
- **动图**：一条长路 → 按 3，在中间点一下切开 → Esc → 选中后半段，Alt 拖端头抬高。约 7 秒。

**合并**
- **文字**：选中几块路面按 Ctrl + J 合成一块。只有同样式、同高度、合起来正好是一个矩形时才能合并，不满足时按钮是灰的。
- **动图**：两块拼成长方形的路 → 框选 → Ctrl + J，变成一块 → 再框选一个 L 形，顶栏的合并按钮是灰的。约 6 秒。

### 1.6 大规模操作

- **文字**：在空白处拖动框选，Shift 加选，Ctrl + A 全选。Ctrl + G 把选中的东西绑成一组，之后点其中任何一个都会选中整组，一起移动、旋转；Ctrl + Shift + G 解组。
- **动图**：一段路加上面的两个机关 → 框选 → Ctrl + G → 点空白取消选择 → 点其中一个机关，整组都选中 → G 一起移动 → Ctrl + Shift + G。约 8 秒。

### 1.7 精细控制

**对齐**
- **文字**：对齐（S，默认开）：移动、拉伸时靠近别的东西的边、中线、顶面会贴过去，并显示绿色参考线；旋转时每 15° 吸一下。
- **动图**：两块错开的路 → G 移动一块，靠近时出现参考线并贴齐 → 左键确定。约 5 秒。

**V 吸附**
- **文字**：按住 V，抓住一个顶点或边中点拖到别的物体上，正好贴到对方的顶点或边中点。斜着放、转过角度的东西也能精确拼上。
- **动图**：一块转了 30° 的路和一块正的路 → 按住 V 抓住一个角 → 拖到另一块的角上松开。约 5 秒。

**格栅**
- **文字**：格栅（Shift + Tab，默认关）：位置和尺寸按步长取整，步长在设置里改（默认 1）。另外方向键也能微调位置（Shift 是 0.1）。
- **动图**：打开格栅 → Ctrl 拖路面端头，长度一格一格跳 → 关掉格栅再拖，长度连续变化。约 6 秒。

## 2. 设计关卡

### 2.1 路面

**路面是一块一块的 box**
- **文字**：BVM 里每块路面都是独立的长方体，块和块之间没有“连接”关系。贴在一起、样式和高度相同的就算一片路面，花纹、开口、转换每次都按位置重新算。所以随便摆、随便改，结果都是对的；重叠的部分只画一次。
- **动图**：三块路随意摆成一个十字 → G 拖动其中一块，花纹实时跟着变。约 5 秒。

**平路、凹路与转换**
- **文字**：路面有平路、凹路、细边框凹路三种。不同样式直接贴在一起不会自动处理，两边各画边框。平路接凹路要放“平凹转换”（长 5，一头平一头凹，放在两段路之间）；凹路接细边框平台用“窄转换”（长 2.5）。转换件只接在路的两端，不能接在路的侧面。
- **动图**：一条平路和一条凹路对接，接缝两边都有边框 → 拉开一段距离，从素材库拖“平凹转换”放进中间，按 R 调方向 → 接缝消失。约 8 秒。

**平台自动衔接**
- **文字**：路接到大平台（宽路面）的侧面时，样式不同也不用手动放转换件，平台的边框里会自动嵌一块衔接。
- **动图**：一个 20×20 的凹路平台 → 拖一条平路接到它侧面 → 镜头推近，看自动嵌进去的衔接块。约 6 秒。

**坡**
- **文字**：坡只在上下两头和别的路相接，侧面不接。
- **截图**：一段坡两头接平路。

参考：[制图手册：路面与钢轨](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/floor-and-rail.html)

### 2.2 钢轨

**单轨、双轨与单双转换**
- **文字**：直轨默认是双轨，在属性面板里切换单轨、双轨、单双转换。Ctrl + 拖改长度，Alt + 拖做坡。
- **动图**：一段双轨 → 属性里切到单轨，再切到单双转换 → Ctrl 拖拉长。约 6 秒。

**弯轨与螺旋**
- **文字**：弯轨在属性里调半径和角度；螺旋调半径、每圈高度和圈数。
- **动图**：放一段弯轨，属性里把角度从 90° 改到 180° → 放一段螺旋，把圈数从 1 改到 3。约 7 秒。

**侧轨**
- **文字**：侧轨是两根成角度的钢轨，拖到路面上会贴住最近的路边；属性里可以把上轨的起点、终点弯下去固定在路边。螺旋侧轨是单轨螺旋，层间距固定 3.6。
- **动图**：一条长路 → 拖侧轨到路边，自动贴上 → 属性里把起点上轨切到“弯下” → 放一段螺旋侧轨。约 8 秒。

**端点闭合与立起来的钢轨**
- **文字**：钢轨两头可以选平直或球形闭合。钢轨能绕 X / Y 转，转 90° 立起来就是一根 Tip。
- **动图**：一段直轨 → 属性里把终点切到“球形” → 选中一段短直轨，R 再按 Y 转 90°，立起来。约 7 秒。

参考：[制图手册：路面与钢轨](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/floor-and-rail.html)

### 2.3 机关与归组

**归组**
- **文字**：游戏靠“组”识别物体：路面要进物理化组、声音组、影子组，机关要进对应的小节。导出 NMO 时 BVM 会按规范自动归好，一般不用管。想了解原理可以看制图手册。
- 参考：[制图手册：归组](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/grouping.html)

**小节**
- **文字**：起点是第 1 小节，每放一个小节盘点多一个小节。新放的机关归到顶栏当前选中的小节，属性面板里能改。在「显示」菜单打开小节标签，机关头上会显示所属小节。
- **动图**：默认场景 → 打开小节标签 → 顶栏切到第 2 小节 → 放一个箱子，标签显示 2 → 属性里改成 1。约 7 秒。

**以推板为例：对准方块**
- **文字**：每个机关都有对准方块（拖动、选中时显示虚线框），它会吸附到路面上，嵌在路面里，路面高度自动对上。推板这种两头接路的机关有两个对准方块：先摆好两段路，把推板拖过去，两个方块分别嵌进两段路的端头，路端会自动开口。机关不会改动路面，路要自己摆。
- **动图**：两段路中间留出空隙 → 拖推板过去，虚线框吸到两段路的端头 → 放下，两个路端的边框消失。约 7 秒。

**挡块与专属路块**
- **文字**：推板这类机关会自动配上原版的木头挡块；选中后每块挡块上有个小圆圈，点一下切换生成或不生成（关掉的显示成红色虚影）。风扇、变球器、栅栏会自动换上专属路块，属性里可以关掉。
- **动图**：选中推板 → 点挡块上的圆圈，挡块变成红色虚影 → 再点一次恢复 → 把风扇拖到路上，脚下换成风扇底座。约 7 秒。

参考：[制图手册：机关与道具](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/module.html)

### 2.4 装饰

**护栏**
- **文字**：按 2 进入护栏工具：点路边放一整条直边，沿路边拖放一段（可以绕过拐角），拖两头的把手改长度。高度、立柱深度等在设置里改，全图生效。
- **动图**：一个 L 形路面 → 按 2，点一条直边 → 沿拐角拖一段 → 拖把手缩短 → Esc。约 8 秒。

**柱子与灯塔**
- **文字**：“柱子（支撑）”对准它头顶的那一格路面，柱头顶在路面底下；“灯塔”是独立的灯柱，放在路边或空地都行。
- **动图**：一段悬空的路 → 从装饰里拖柱子到路下面，吸到路底 → 拖一个灯塔放在旁边。约 6 秒。

**云层**
- **文字**：装饰里有云层和漩涡云层，一张图只导出一个。「显示」菜单可以在编辑器里隐藏云层，不影响导出。
- **截图**：放了漩涡云层的场景，远景。

参考：[制图手册：游戏内装饰](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/decoration.html)

### 2.5 死亡区

- **文字**：死亡区在机关标签里，球碰到就死。和路面一样能拉伸、移动；导出时自动隐藏并归进 DepthTestCubes 组。「显示」菜单可以在编辑器里隐藏它。
- **动图**：一条路下方 → 拖一个死亡区放下 → Ctrl 拖成一大片 → 「显示」里关掉、再打开。约 6 秒。

参考：[制图手册：死亡区](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/depth-test-cube.html)

## 3. 文件与分享

### 3.1 导出 NMO

- **文字**：文件 → 导出 NMO，在浏览器里直接生成，文件名就是顶栏的地图名。放进游戏的地图目录就能玩。没有起点或终点气球时会提示。
- **截图**：文件菜单展开；再配一张游戏内的截图。
- 参考：[制图手册：NMO 文件](https://ghomist.github.io/ballance-mapping-manual/mapping/basic/nmo-file.html)

### 3.2 地图码

- **文字**：文件 → 复制地图码，得到一串文字，发给别人；对方用“导入地图码”粘贴就能打开。
- **动图**：一张小图 → 文件 → 复制地图码 → 新建 → 文件 → 导入地图码，粘贴，地图回来。约 8 秒。

### 3.3 历史地图

- **文字**：地图自动存进历史，最多留 100 张，Ctrl + O 打开列表，可以重命名、删除。历史只存在这台电脑的这个浏览器里，清除网站数据就没了，重要的图记得另存地图码。
- **截图**：历史地图列表。

## 4. 常见问题

- 为什么这里出边框 / 为什么没接上：样式不同、高度差一点点、手动设成了封口，或者路面绕 X / Y 倾斜了（倾斜的路面单独成网格）。
- 为什么倾斜的钢轨拖不动：倾斜后长度和高差要在属性面板里改。
- 为什么机关没有挡块或专属路块：机关倾斜了，或者在属性里关掉了。
- 进游戏后漩涡云层是黑的、球有两层影子：旧版本导出的，重新导出一次。

## 录制约定

- 960×540、15 帧，亮色主题，录制前隐藏帧数和素材库以外的弹窗。
- 按键时在画面角落显示按下的键，样式参照漫游 HUD 的按键。
- 每张动图开头停半秒、结尾停一秒再循环，让人看清前后对比。
- 只有截图或纯文字的项：1.1、2.1 的坡、2.4 的云层、3.1、3.3、4、5。
