# Ballance Vibe Mapping

一个只关心赛道走向与结构的 Ballance 制图器：路面材质的衔接、UV、平凹转换都由程序自动处理。

在线版本：https://ghomist.github.io/ballance-vibe-mapping/（推到 master 后由 GitHub Actions 自动发布；线上版本可以直接导出 NMO，只有 .blend 需要本地运行）

## 运行

```bash
npm install
npm run assets     # 生成预览素材：贴图、资产库模型（盘点路面、护栏、灯柱、假机关）、BBP 机关占位符
npm run dev
```

`public/` 下的贴图、资产库模型和机关占位符已经提交在仓库里，直接 `npm run dev` 就能用；重新生成需要本机装有 Ballance、Blender 和 BBP（`npm run assets`）。路径默认是 `D:/Ballance/Textures`、`D:/BlenderLibrary/BallanceAssets/BallanceAssets.blend`、`D:/Blender/blender.exe`，可以用环境变量 `BALLANCE_TEXTURES`、`BALLANCE_ASSETS`、`BLENDER`、`BBP_DIR` 指定其它位置。

## 导出

工具栏「导出」：

- **导出 NMO**：直接在浏览器里生成（纯前端，不需要 Blender），放进 Ballance 的关卡目录就能玩。内容与 Blender + BBP 导出的一致：路面按连通块合并成 `A_Floor_*`，钢轨为 `A_Rail_*`，都使用 BME 材质和 BBP 的归组；盘点路面、护栏、装饰取自资产库；机关用 BBP 占位符并按规范命名（`P_Box_01_01`…）、归入各自小节；补齐 `Sector_01…N`。贴图只存文件名，游戏从自己的 Textures 目录读取。
- **导出 Blender 文件**：开发服务器调用本机 Blender + BBP 生成 .blend，可以继续手工修改（线上版本不可用）。
- **导出场景描述**：JSON 文件，可在 Blender 里运行 `scripts/blender/build_scene.py` 自行生成。

命令行：`npm run export -- map.bvm [--nmo out.nmo] [--blend out.blend] [--json out.json] [--blender]`。.nmo 默认用内置写入器生成，加 `--blender` 改用 Blender + BBP。

### NMO 写入器

`src/export/nmo.ts` 是 Virtools 文件格式的写入器，照搬 [libcmo21](https://github.com/yyc12345/libcmo21)（BBP 背后的 BMap）的保存流程，只实现地图需要的组、3D 物体、网格、材质、贴图（外部文件名），整体 zlib 压缩（浏览器自带的 `CompressionStream`）。`src/export/nmo-scene.ts` 把场景描述组装成 Virtools 文档，处理方式与 Blender 一致（合并重合顶点、路面平直法线、钢轨平滑法线与 BBP 的反射 UV、坐标与绕序转换）。

资产库物体、机关占位符的网格和所有材质、贴图参数来自素材库 `public/nmo-lib.json`：`npm run nmo-lib` 让 Blender + BBP 导出一个包含全部资产、机关和材质的“目录”关卡，再用 BMap 读回来生成（只在资产库或 BBP 更新时需要重跑）。`npm run nmo-check [map.bvm]` 把同一张地图分别用网页端和 Blender + BBP 导出，用 BMap 读回来逐项对比（物体、矩阵、组、逐面几何、材质、贴图）。

## 操作

左键操作前，鼠标所在位置会显示示意（蓝色：可操作，红色：不可操作并说明原因）。

| 操作 | 效果 |
|---|---|
| 左键拖端点 | 沿路方向拉长 / 缩短；分支拉回 0 即删除；斜坡顶端往外拉会续接一段平路 |
| 左键拖路的侧面 | 在示意框处开路口（落在末端那一格即为拐弯），斜坡上禁止 |
| 左键拖路块 / 平台的边 | 从空端口长出新路 |
| Shift + 左键拖侧面 | 整个侧面拉成大平台；平台的边可往外拉或往里推；相邻同高平台自动合并；普通 / 凹槽平台推回只剩 5 宽时自动变回路面（5×5 变 1×1，5×L 变直道，长边上的路成 T 字路口），细边花纹平台不变，改成普通 / 凹槽后再变 |
| Alt + 左键拖 | 坡面：拖截面或路块调整高度，下游跟随，中间自动成坡；按住 Alt 悬停时预览：绿框随之升降、橙虚线变成坡道，其余保持不动 |
| Ctrl | 显示六向移动手柄并高亮“这一块”（两个折点之间的直路，或单个路块 / 平台）；悬停箭头时预览移动边界：蓝框整体平移、黄虚线伸缩 / 成坡；接在平台边上的路沿边移动时只滑动路口；不可行的方向变暗 |
| 空白处按住拖动 | 框选多个路面 / 钢轨 / 物件（Shift 追加，Esc 取消）；Ctrl 手柄整体移动选中的一坨，X / Del 删除 |
| 双击空白 / 右键空白 | 新建独立的 1×1 路块；右键空白还可以新建起点 / 小节盘点（新建地图时自带一个起点） |
| 右键直道 | 「在此放置小节盘点」：这一段路换成盘点路面（两侧接到延伸段末端）；端点处「在端点接上起点」；护栏开关 |
| 右键盘点 | 路面旋转（没接路时，重生朝向一起转）、重生朝向转 90° / 掉头（指着盘点按 R 也可以）、小节提前 / 推后。重生点默认朝着起点出口 / 顺着路往前 |
| 右侧机关库 | 每个机关 / 装饰都有名称（取自 Ballance Wiki）和预览图；按住卡片拖到视图里松开即放下，拖动中 R 转向，右键或 Esc 取消。机关跟着鼠标走，占位符里的对准方块吸附到路面上——方块的面优先与路的两头贴齐（优先于格栅和自动对齐），其次落在格子上；哪个方块离得最近就用哪个，秋千、跷跷板这类有两个方块的可以跨在缺口两边，浮板两头的窄条贴着路端。拖路面端点时也优先贴齐已放机关的对准方块。关掉格栅对齐后对准方块可以沿路连续放（例如栅栏放在一段直路的任意位置）。悬停、选中、拖动机关时用虚线框显示它的对准方块。已放的物件在编辑模式下直接拖动移动，Alt 拖调高度，R / Shift+R 转向；也可以按住 Ctrl 用手柄自由移动，专属路面、挡块跟着走——离路面很近时吸到路上并替换路面，否则在原地单独放一块底座；右键设置小节、开关挡块 |
| 3 护栏 | 点路边：沿这条直边（拐角到拐角）放一段护栏；沿路边拖：自由长度，可以绕过拐角；拖护栏端头调长度（吸附拐角、格栅）；X 删除。护栏是独立的对象，不绑定某段路 |
| 工具栏「设置」 | 全图设置：护栏顶部高度、立柱深度、离路边距离、管半径、铆钉深度、道具离地高度，改了整张图生效（可撤销）。显示：机关显示成机关模型（资产库「机关模型」里的假机关，默认）还是 BBP 占位符，机关库的预览跟着切换——只影响编辑器里的显示，对准方块吸附、断路、导出都按占位符。点面板外面自动收起 |
| X / Del | 删除选中的元素（没有选中时删除鼠标下的元素） |
| 拖路端点连接 | 靠近能接上的地方会吸过去并显示绿框：只自动接同一高度的；按住 Alt 时高度不同的也接（本段变成坡） |
| E | 切换端点封闭 / 开放；开放端点正对另一个开放端点、路块空端口或平台开口（高度、样式一致）时自动接上 |
| G / 工具栏「格栅对齐」 | 格栅对齐：一切对齐到 2.5 的倍数（含高度，物件为 1.25）。拖动途中按住 Alt 临时开 / 关格栅（按钮显示虚线框），松开或结束拖动后恢复 |
| S / 工具栏「自动对齐」 | 自动对齐：靠近其它元素的边界、端点和高度时对齐过去，并显示对齐参考线。与格栅相互独立：都开时优先对齐（距离不超过半格），没对上再取格点；都关时完全自由。拖路端点时的自动连接（绿色提示框）常驻，不受这两个开关影响 |
| 按住 C 分隔 | 按住 C 时点击截面，把路面或钢轨分开成独立的两段（松开 C 回到原来的工具），两侧是可见的封闭端点（断开都是显式的） |
| 2 钢轨 | 和路块一样拉出钢轨（双轨，最顶端与路面顶面对齐）：直道端面或侧面、路块 / 底座 / 盘点的空路口、平台边，或在空地上按住拖。钢轨两头的操作和路面端头一样，悬停时显示截面（扁平的蓝色块）和当前拉法：直接拖 = 直线伸缩（坡顶往外拉接一段水平的）；Shift = 拐弯；Alt = 端头上下移动成坡；Shift+Alt = 螺旋（左下角对话框调方向、半径、每圈高度、圈数，边改边预览）。直线拉到另一条钢轨的端头或路边附近会吸过去，接上钢轨时合成一条。拖动中切换 Shift / Alt 立刻换拉法。Ctrl 手柄移动，按住 C 点击分隔（圆弧、螺旋上也行），右键切换双轨 / 单轨 / 单双转换、编辑螺旋、与相接的钢轨合并。接在路面端头上的钢轨会跟着路面伸缩、移动和升降 |
| 右键 | 普通 / 凹槽 / 细边花纹平台切换、连接、插入截面、设为高度基准、删除等 |
| 中键 / Shift+中键 / 滚轮 | 环视（绕着选中的东西转，没有选中时绕离画面中心最近的物体转，视图不挪）/ 平移 / 缩放 |
| F | 视角对正并拉近选中的东西（点选时视图会自动平移到选中的东西上，但不拉近） |

盘点路面直接使用资产库模型：接了路的一侧自动换成带延伸段的版本，火焰和重生点占位符按 BBP 小节对的偏移放置（四火转 90°，重生点抬高 3.65 / 3.3258）。起点固定是第 1 小节，每个小节盘点激活下一个小节。机关默认归入它所在路段前面那个盘点的小节：从机关脚下的路面沿路网扩散，碰到的盘点里小节号最小的就是它的小节。路面升降时，放在上面的机关和装饰跟着升降。

护栏与原版一致：一整段连续的钢管，贴着路边外侧走（管中心离路边 0.25），横杆顶部默认离路面 2.6（原版约 3.37），拐角处圆弧过渡，只在两头有立柱沿路面侧面默认插到路面以下 2（手册为 1.5），立柱上各有一个铆钉（`RailNail`，路面以下 0.7）；坡道上顺着坡走。这些数值都可以在设置里改。护栏沿“路面外沿”走——所有露在外面的路边连成的环，路面改动后护栏的起止点会重新落到最近的外沿上。导出时护栏是 `Phys_FloorRails` 钢轨物体，铆钉是不归组的装饰。

机关专属路面（参照原版关卡）：变球器放上去时脚下那一格换成对应材质的 `TrafoBase_*`；风扇换成 `Ventilator_*` 底座，按哪几边接着路选边框花纹；栅栏（Modul 01）换成两格长的原版栅栏路面 `Slider`：第一格就是栅栏所在的那一格路面，第二格朝栅栏被推的方向延伸（栅栏横在路上时伸到路外，末端可以接推栅栏用的路）。专属路面是路网里的节点，两侧照常接路；机关删掉或挪走后变回普通路面。机关不在路面上时，专属底座单独放在机关下面（不接路），删掉机关时一起去掉。从中间断开的机关（秋千、推板、双向挡板、软木桥、跷跷板、落石、T 型板、浮板）放在一段直路中间时，自动去掉两个对准方块之间的那段路（T 型板是两个侧边方块、也就是两个挡块中间；双向挡板是两条平行的路各断一段），断开处是开放端点；机关挪走或删掉后，两侧的路重新接回一整段。Modul 19 / 25 / 30 / 37 自动配上原版的木头挡块（`Phys_FloorStopper`，模板取自原版关卡），可在右键菜单里关掉。道具球、变球器按材质着色。

平台与路面衔接时，自动在平台边框带内部嵌入长 2.5 的衔接块，路面长度不变：普通路接凹槽平台用半块平路（平台内侧下沉 0.7），凹槽路接普通平台用窄平凹转换，凹槽路接细边花纹平台用窄平凹转换并把平台内侧两个顶点下沉 0.7，样式相同时由两块 1/4 内角拼接（与 T 字路口一致）。构造路面一律平直着色。

## 结构

- `src/model`：路网数据模型（路块、接头、直道、平台、钢轨、盘点、物件）与编辑操作
- `src/export/scene.ts`：导出场景描述；`src/export/nmo.ts`、`nmo-scene.ts`：网页端 NMO 导出；`scripts/blender/build_scene.py`：在 Blender 里用 BBP 生成地图；`scripts/blender/dump_nmo.py`：用 BMap 把 .nmo 读成 JSON
- `src/geom/floor.ts`：按 2.5×2.5 四分之一格自动拼接边框贴图，生成路面网格
- `src/editor.ts`：Three.js 视图与交互
- `tests/run.ts`：场景测试（`npm test`）
