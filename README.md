# Ballance Vibe Mapping

一个只关心赛道走向与结构的 Ballance 制图器：路面材质的衔接、UV、平凹转换都由程序自动处理。

## 运行

```bash
npm install
npm run textures   # 从 D:/Ballance/Textures 复制预览贴图（可传参指定其它目录）
npm run dev
```

## 操作

左键操作前，鼠标所在位置会显示示意（蓝色：可操作，红色：不可操作并说明原因）。

| 操作 | 效果 |
|---|---|
| 左键拖端点 | 沿路方向拉长 / 缩短；分支拉回 0 即删除；斜坡顶端往外拉会续接一段平路 |
| 左键拖路的侧面 | 在示意框处开路口（落在末端那一格即为拐弯），斜坡上禁止 |
| 左键拖路块 / 平台的边 | 从空端口长出新路 |
| Shift + 左键拖侧面 | 整个侧面拉成大平台；平台的边可往外拉或往里推；相邻同高平台自动合并 |
| Alt + 左键拖 | 坡面：拖截面或路块调整高度，下游跟随，中间自动成坡 |
| Ctrl | 显示六向移动手柄并高亮“这一块”（两个折点之间的直路，或单个路块 / 平台）；拖箭头只移动这一块，相邻路面自动伸缩 / 成坡；不可行的方向变暗 |
| 双击空白 / 右键空白 | 新建独立的 1×1 路块 |
| E | 切换端点封闭 / 开放；开放端点正对另一个开放端点、路块空端口或平台开口（高度、样式一致）时自动接上 |
| G 或工具栏「格栅」 | 格栅模式：一切对齐到 2.5 的倍数（含高度）；关闭后自由拖动，吸附到其它元素的边界、端点和高度，并显示对齐参考线 |
| 2 分隔 | 点击截面把路面或钢轨分开成独立的两段，两侧是可见的封闭端点（断开都是显式的） |
| 3 钢轨 | 从路面端点拖出钢轨（最顶端与路面顶面对齐）；钢轨端头沿方向拉长 / 缩短，末端侧面拖出拐弯；Alt 拖末端调坡度；右键切换双轨 / 单轨 / 单双转换、接螺旋 |
| 右键 | 普通 / 凹槽 / 细边花纹平台切换、连接、插入截面、设为高度基准、删除等 |
| 中键 / Shift+中键 / 滚轮 | 环视 / 平移 / 缩放 |

平台与路面衔接时，自动在平台边框带内部嵌入长 2.5 的衔接块，路面长度不变：普通路接凹槽平台用半块平路（平台内侧下沉 0.7），凹槽路接普通平台用窄平凹转换，样式相同时由两块 1/4 内角拼接（与 T 字路口一致）。构造路面一律平直着色。

## 结构

- `src/model`：路网数据模型（路块、接头、直道）与编辑操作
- `src/geom/floor.ts`：按 2.5×2.5 四分之一格自动拼接边框贴图，生成路面网格
- `src/editor.ts`：Three.js 视图与交互
- `tests/run.ts`：场景测试（`npm test`）
